# V9 Architecture Cut

V9 separates architectural contracts by scope.

```text
Root
→ product model, Domains, Journeys, authorization, ownership and cross-system boundaries

Frontend
→ Apps, Pages, Hooks, Services, Presentation Lake, Storybook, Feature Management consumer, Feature Flags and mobile behavior

BFF
→ consumer-facing APIs, authorization resolution, Journey orchestration and backend adaptation

Backend
→ authoritative Domain behavior and source of truth
```

The frontend architecture defines:

```text
3 Web Apps + 2 Mobile Apps
```

Web: `clients-webapp` (bootstrapped, Nuxt 4), `partners-webapp` (planned), `backoffice-webapp` (planned).

Mobile: `clients-app` (planned), `partners-app` (planned).

Portal Guanabara implements V9 on Vue 3 + Nuxt 4; the contracts are framework-independent except where `apps/AGENTS.md` §4, §23 and §24 describe Nuxt mechanics.
