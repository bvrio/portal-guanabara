# V0 Journey Seed

The V0 seed Pages are:

```text
Authentication
├── Login
└── Registration

Home
└── Home

User
├── Details
└── Management
```

Every Journey should be born complete enough to exercise the architecture:

```text
Manifest
Page
Hook
Service
Presentation
Mock BFF operation or real BFF operation
```

## Status — clients-webapp v0.2 ✅ complete

Product decision: the User Journey has an **Overview hub** plus the two seed Pages.

Cross-cutting pieces delivered with the seed:

- Journey Manifests package + validation.
- Mock BFF on Nitro (`/mock-bff/*`) with cookie session and personas.
- Feature Management consumer, Feature Flags, route-derived tracking.
- `NuxtLink` adapter for the Presentation Lake `Link` (client-side navigation).
- DEV toolbar: persona switch + flag overrides.
